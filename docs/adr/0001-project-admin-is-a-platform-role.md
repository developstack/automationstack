# 项目管理员是平台角色，管理项目要同时满足两个条件

平台角色有三个：平台管理员、项目管理员和普通用户。我们把"项目管理员"放在平台级，没有放在项目级。原因是 Casdoor 里没有平台的项目，Casdoor 只能给用户一个全局角色。只有放在平台级，Casdoor 的初始化数据和角色同步才能直接给出项目管理员。

用户管理一个项目，必须同时满足两个条件：用户是这个项目的项目 owner，并且平台角色至少是项目管理员。只有项目管理员和平台管理员可以成为项目 owner。项目管理员降级为普通用户时，平台保留他的项目 owner 记录，只暂停管理权限。他恢复为项目管理员后，权限自动恢复。

## Considered Options

- **只用项目角色（项目 owner）**：这是原来的模型，任何用户都可以新建项目并成为项目 owner。这个方案被拒绝，原因是普通用户不能管理项目，而且 Casdoor 无法按项目分配角色。
- **降级时删除项目 owner 记录**：这个方案被拒绝。角色同步可能来回变化，删除记录会丢失数据，无法恢复。

## Consequences

- 这个决定实施时，生产环境没有真实用户和项目，所以平台不迁移数据。所有现有的 `member` 都成为普通用户。
- 一个项目可能只有暂停权限的项目 owner。这时只有平台管理员可以管理这个项目。
