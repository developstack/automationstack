# 测试任务不能删除，只能作废

测试任务记录了一次评审和执行的结论，是项目测试历史的一部分。我们去掉了测试任务的删除功能，界面、MCP 工具和后端接口都不再提供删除。不再需要的测试任务由创建者、项目 owner 或平台管理员作废。作废的测试任务保留在项目中，只能查看，不能恢复。

## Considered Options

- **保留删除，只在界面上隐藏**：这个方案被拒绝。MCP 工具和接口仍然可以删除，规则会被绕过。
- **平台管理员保留删除权限，用来清理测试数据**：这个方案被拒绝。一个例外会让"测试历史完整"这个前提不再成立。

## Consequences

- 用例只要被一个测试任务用过，就不能删除，只能改为「废弃」。测试任务已作废时也是这样。
- 作废的测试任务不计入项目概览的统计，包括进行中的测试任务、用例最近一次的执行结果和覆盖率。
- 测试数据不能清理，只能作废。
